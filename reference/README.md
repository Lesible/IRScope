# Reference Attachments

- `original-program/bin/`: original Windows EXE/DLL files used as reverse-engineering evidence.
- `original-program/samples/`: sample JPG files used by tests and demos.
- `original-program/logs/`: original log files.
- `reverse-engineering/`: generated inventory, strings, objdump output, interface sketches, and disassembly references.

These files are not required by the Java runtime except the sample JPGs used by tests/demo.
